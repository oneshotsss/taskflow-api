# Defense

## 1. Що і навіщо
Taskflow API — це навчальний бекенд для управління задачами на базі Node.js. Створений для демонстрації налаштування середовища, перевірки коду, стандартів та архітектури.

## 2. Топ-3 розбіжності / зрізані кути (проти spec)
1. **Зберігання даних у пам'яті:** Замість повноцінної БД використовується масив в пам'яті (відсутня персистентність). Коміт: a7ac66ac75909b724cce6efd19b51c66d6ece105
2. **Відсутність валідації сутностей:** Моделі не валідуються суворо (немає перевірки форматів або унікальності). Коміт: a7ac66ac75909b724cce6efd19b51c66d6ece105
3. **Мінімалістичний роутінг:** Відсутня автентифікація і прив'язка задач до конкретного користувача через токени (усі задачі глобальні для спрощення). Коміт: a7ac66ac75909b724cce6efd19b51c66d6ece105

## 3. Ключове рішення
**Express.js + Шарувата архітектура** (деталі у [ADR-0001](docs/adr/0001-express-layered-architecture.md)). Альтернативами були Fastify (швидше, але може вимагати більше часу на ознайомлення) або `http` модуль Node.js (надто багато низькорівневого коду). Express обрано за простоту, а розбиття на шари (Routes, Controllers, Services) забезпечує легке тестування і відповідає стандартам чистого коду.
