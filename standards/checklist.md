# Quality Checklist

- [ ] Does the implementation match the Acceptance Criteria in `spec.md`?
- [ ] Are boundaries between modules clear and justified?
- [ ] Are all newly introduced dependencies strictly necessary?
- [ ] Is `npm run lint` passing without warnings/errors?
- [ ] Is `npm run test` executing successfully?
- [ ] Did pre-commit hooks verify code format successfully?
- [ ] Are relevant ADRs published for any new major structural decisions?
